// Abstract

Morphometric measurements collected from adult ERS_F specimens (n=84) across forelimb skeletal elements including humerus, radius, ulna, and associated cartilage. Data collected via digital calipers and photogrammetric landmark digitisation. Associated curve analysis and modulus data included for each specimen. All raw CSVs, analysis outputs, and metadata provided.
