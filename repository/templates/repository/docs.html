Uploading an Experiment

  1. Create an account or sign in
  2. Click + Upload in the navigation bar
  3. Fill in the experiment title, abstract, category, and license
  4. Attach your data file (CSV, XLSX, JSON, ZIP — max 150 MB)
  5. Optionally attach an analysis notebook (.ipynb)
  6. Submit — your experiment will appear immediately

Sample Records

Each experiment can have a structured sample table. Columns are grouped as Sample characteristics (descriptive fields) or Sample data (numeric measurements). Samples can be added manually, imported via CSV, or browsed globally across all experiments from the Samples tab.

Sample photosMultiple images per sample
Global searchFilter across all experiments

Sample ID

Every sample requires a unique Sample ID within its experiment. IDs should be short, human-readable, and consistent across an experiment.

Recommended formatAlphanumeric, no spaces (e.g. S-01, MYC-003)
CaseUse a consistent case — mixed case is allowed
UniquenessMust be unique within an experiment

Column Names

Column names define the fields in the sample table. Use clear, descriptive names so that samples are interpretable across experiments.

FormatTitle case preferred (e.g. Substrate Type, Tensile Strength)
UnitsInclude units in brackets (e.g. Mass [g], Temperature [°C])
Reserved namesSample ID and Type are built-in — do not use as column names

Column Groups

Every column belongs to one of two groups, which controls where it appears in the sample table.

CharacteristicsDescriptive / categorical fields (species, substrate, treatment, etc.)
DataNumeric measurements (mass, strength, conductivity, etc.)
Auto-detectionCSV import assigns groups based on >50% numeric values
OverrideGroup can be changed manually via the column edit dropdown

CSV Structure

When importing samples via CSV, the file must follow this structure:

First rowHeader row with column names
Sample ID columnMust be named Sample ID (case-insensitive)
Type columnOptional — maps to the built-in Type field
Additional columnsAny number of characteristic or data columns
Empty cellsAllowed — recorded as blank values
EncodingUTF-8 recommended
