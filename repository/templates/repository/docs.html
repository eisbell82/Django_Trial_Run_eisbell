Uploading an Experiment

  1. Create an account or sign in
  2. Click + Upload in the navigation bar
  3. Fill in the experiment title, abstract, category, and license
  4. Attach your data file (CSV, XLSX, JSON, ZIP — max 150 MB)
  5. Optionally attach an analysis notebook (.ipynb)
  6. Submit — your experiment will appear immediately

Sample Records

Each experiment can have a structured sample table. Columns are grouped as Sample characteristics (descriptive fields) or Sample data (numeric measurements). Samples can be added manually, imported via CSV, or browsed globally across all experiments from the Samples tab.
