SpecimenBase

A curated open repository for biological specimen datasets. Upload, discover, and cite research-grade data with associated provenance records and analysis notebooks.

Getting Started

Browse datasetsNo account required
Download filesNo account required
Upload datasetsAccount required
Manage datasetsAdmin access required

Uploading a Dataset

  1. Create an account or sign in
  2. Click + Upload in the navigation bar
  3. Fill in the dataset title, abstract, category, and license
  4. Attach your data file (CSV, XLSX, JSON, TIFF, ZIP — max 2 GB)
  5. Optionally attach an analysis notebook (.ipynb)
  6. Submit — your dataset will appear immediately

Supported File Types

Tabular dataCSV, TSV, XLSX
Structured dataJSON
ImagingTIFF
ArchivesZIP
Notebooks.ipynb (Jupyter)
